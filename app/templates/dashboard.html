Integraciones API

El Gateway es 100% compatible con el formato de API de OpenAI.

curl (Terminal)

curl -X POST "http://IP_SERVIDOR:8000/v1/chat/completions" \
  -H "Authorization: Bearer TU_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"llama3.1:8b",
    "messages":[{"role":"user","content":"Hola"}],
    "client_id":"pc-diseno-01"
  }'

n8n / Make

  • Nodo: OpenAI Chat Model
  • Base URL: http://IP_SERVIDOR:8000/v1
  • API Key: Generada en este panel
  • Model: El nombre exacto de Ollama

Node.js / Python SDK

  • Instancia el cliente oficial de OpenAI.
  • Cambia baseURL apuntando al puerto 8000 del servidor.
  • Añade el header client_id si deseas separar las métricas por aplicación.

Cliente CLI remoto

Instala la interfaz de terminal en otros equipos de la red para que chateen usando este servidor.

Linux / macOS (bash)

curl -fsSL {{ server_base_url }}/install.sh | bash

Windows (PowerShell)

irm {{ server_base_url }}/install.ps1 | iex

Uso después de instalar

Abre una nueva terminal en el otro PC y ejecuta:

lanllm setup lanllm chat
